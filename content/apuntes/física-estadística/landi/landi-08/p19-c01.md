Example : EUF 2014-1

Consider a system of \(N\) non-interacting magnetic atoms,  
whose magnetic moments \(\vec{\mu}\) can point in only 3 directions  
the energies in the 3 directions are

$$\begin{aligned}
E_0&=-\mu H\\
E_1&=E_2=0
\end{aligned}\tag{41}$$

The ground state will depend on the sign of \(H\)

• If \(H>0\) ; \(gs=0\)

• If \(H<0\) ; \(gs=1,2\) => 2-fold degeneracy.

The partition function is

$$\begin{aligned}
z_1&=\sum_m e^{-\beta E_m}=2+e^{\beta\mu H}\longrightarrow z=z_1^N
\end{aligned}\tag{42}$$

So.

$$\begin{aligned}
F&=-k_BT\ln z=-Nk_BT\ln(2+e^{\beta\mu H})
\end{aligned}\tag{43}$$
