But in the present problem there is an additional property: each value of $k$ will define a different eigenvector: $A_m = B e^{ikma}$ so

$$\vec{A}=B\begin{pmatrix}e^{ika}\\e^{2ika}\\\vdots\end{pmatrix}$$

$k$ is actually the label of the eigenvalue/eigenvectors. But our matrix $W$ is $N\times N$ and must therefore have $N$ eigenvectors, whereas Eq (54) actually gives an infinite number of $k$ values
