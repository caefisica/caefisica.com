Now we assume that the lattice spacing is very small so we  
don't have to worry about the fine details about the individual  
site. So. we think about taking a 'continuum limit'. Each  
$q_m$ represents the displacement at position $x_m$, so we define  
a continuous displacement field

$\phi(x_m) = \frac{q_m}{\sqrt{a}}$

I know this seems weird, but it will make sense in a  
moment. the LHS of (69) then becomes

$$\begin{aligned}
m\ddot{q}_m &= \sqrt{a}\,m\left(\frac{\partial^2\phi}{\partial t^2}\right)
\end{aligned}\tag{70}$$
