The customary choice is to take $B$ real, which implies

$B = 1/N$. Thus we finally conclude that

Eigenvectors of the cyclic matrix $W$ in (50)

$$\begin{aligned}
\vec{A}_k &= \frac{1}{\sqrt{N}}
\left(\begin{array}{c}
e^{ika}\\
e^{2ika}\\
\vdots
\end{array}\right),
\qquad A_{k,m}=\frac{1}{\sqrt{N}}e^{ikx_m}\\
k&=\frac{2\pi\ell}{Na},\qquad -\frac{N}{2}<\ell\leq\frac{N}{2}\\
k&\in\left[-\frac{\pi}{a},\frac{\pi}{a}\right]
\end{aligned}\tag{57}$$

This is a very important result. It is true for a matrix of arbitrary size, as long as it is cyclic. And cyclic matrices appear quite often in all areas of physics.

If we now return to Newton's law (42), we see that one possible solution will be

$$\begin{aligned}
q_m(t)&=e^{i(kx_m-\omega_k t)}
\end{aligned}\tag{56}$$

This is a plane wave: vibrations propagate through matter like waves. The most general solution will then be given by linear combinations of plane waves

(General Solution)

$$\begin{aligned}
q_m(t)&=\sum_k c_k e^{i(kx_m-\omega_k t)}
\end{aligned}\tag{57}$$
