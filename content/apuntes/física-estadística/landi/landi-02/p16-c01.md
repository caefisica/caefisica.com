The Dirac $\delta$ function as a prob. distribution

The Dirac $\delta$ function is defined as

$$\begin{aligned}
\delta(x)&=\begin{cases}
0 & x\ne 0\\
\infty & x=0
\end{cases}
\qquad \text{but}\qquad
\int_{-\infty}^{\infty}\delta(x)\,dx=1
\end{aligned}\tag{35}$$

If $f(x)$ is an arbitrary function, it then follows that

$$\begin{aligned}
\int_{-\infty}^{\infty}f(x)\delta(x-x_0)&=f(x_0)
\end{aligned}\tag{36}$$

So $\delta(x-x_0)$ functions as a "window", which takes only the part  
of $f(x)$ around $x_0$
