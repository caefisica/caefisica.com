Integral representation of the $\delta$-function

there is a way to represent the $\delta$ function which is  
really, really really useful in practice:

$$\begin{aligned}
\delta(x)&=\frac{1}{2\pi}\int_{-\infty}^{\infty}e^{ikx}\,dk
\end{aligned}\tag{40}$$

this formula is worth remembering. It could save you life  
one day.

Before we prove it, let us try to understand it. if $x=0$ we

$$\int_{-\infty}^{\infty}1\,dk=\infty$$

which agrees with (35). When $x\ne0$ the integral can be split into  
sines and cosines. These oscillate indefinitely, which leads to  
destructive interference. Hence when $x\ne0$ we get 0.

To prove Eq (38) consider first the following integral ($x>0$)

$$\begin{aligned}
\frac{1}{2\pi}\int_{-\infty}^{\infty}e^{ikx-x|k|}\,dk
&=\frac{1}{2\pi}\int_{0}^{\infty}e^{(ix-x)k}\,dk
+\frac{1}{2\pi}\int_{-\infty}^{0}e^{(ix+x)k}\,dk\\
&=\frac{1}{2\pi}\left.\frac{e^{(ix-x)k}}{ix-x}\right|_{0}^{\infty}
+\frac{1}{2\pi}\left.\frac{e^{(ix+x)k}}{ix+x}\right|_{-\infty}^{0}\\
&=\frac{1}{2\pi}\left[\frac{1}{x-ix}+\frac{1}{x+ix}\right]\\
&=\frac{1}{2\pi}\left[\frac{x+ix+x-ix}{x^2+x^2}\right]\\
&=\frac{1}{2\pi}\frac{2x}{x^2+x^2}
\end{aligned}$$
