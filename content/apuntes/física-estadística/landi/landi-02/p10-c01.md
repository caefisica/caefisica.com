Random number generators

Generating random numbers in a computer is extremely important in physics in general and statistical mechanics in particular. They are used specially in a method called Monte-Carlo simulations, which we will discuss later on.

Generating random numbers is also an art. And one which has been evolving quickly in recent years. If you ever encounter this type of problem I suggest you never try to implement a random number generator by yourself. Use an implementation made by a professional. Not only will it be faster than yours, it will also be more reliable: a crappy random number generator will give wrong physical answers to your simulations.

The important distributions like $\operatorname{Unif}(0,1)$ and $N(0,1)$ have dedicated generators. If you want to generate some other distribution, then you first generate $\operatorname{Unif}(0,1)$ and then use the following transformation method.

Let $U\sim\operatorname{Unif}(0,1)$ be a uniform r. v. Also let $X$ be some r.v. you want to simulate, with $F(x)$ being its corresponding CDF. Then the following worth remembering:

If $U\sim\operatorname{Unif}(0,1)$ then $X=F^{-1}(U)\sim F$
