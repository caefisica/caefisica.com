$\ln N! = \ln [N(N-1)(N-2) \cdots 1]$

$= \ln N + \ln(N-1) + \cdots + \ln(1)$

$= \sum_{m=1}^{N} \ln(m)$

Assuming $N$ is large, I want to approximate this sum  
by an integral. There is a trick to do this which always  
works: convert your sum to a Riemann sum

$\int_a^b f(x)dx \approx \sum_{m=1}^{N} \Delta x\, f(x_m)$

In our case we first define $x_m = \frac{m}{N}$, then we rewrite

$\ln N! = \sum_{m=1}^{N} \ln(Nx_m) = N\ln N + \sum_{m=1}^{N} \ln x_m$

Now we only need to worry about the last term. we first

note that since $x_m = \frac{m}{N}$,

$\Delta x = \frac{1}{N}$

Thus when $N$ is large $\Delta x$ will be tiny.
