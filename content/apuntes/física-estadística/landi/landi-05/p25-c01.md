There is, however, one problem with this : some sites don't  
have links to any other site ; they are absorbing states  
(the random surfer gets trapped here).

The solution they found to this problem is to use the idea  
of teleportation. The surfer is randomly surfing the web.  
Each time he reaches a new site he flips a coin with  
probability $\alpha$ ($\sim \operatorname{Bern}(\alpha)$).

• If the coin lands 1: randomly click on any link of  
                                     that site

• If the coin lands 0: move randomly to another  
                                     arbitrary page in the web.
