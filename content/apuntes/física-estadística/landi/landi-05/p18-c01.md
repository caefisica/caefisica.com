Now multiply by Q again!

$$\begin{aligned}
Q^2\vec{p}(0) &= Q[Q\vec{p}(0)]\\
&= c_1\lambda_1 Q\vec{x}_1 + c_2\lambda_2 Q\vec{x}_2 + \cdots\\
&= c_1\lambda_1^2\vec{x}_1 + c_2\lambda_2^2\vec{x}_2 + \cdots
\end{aligned}$$

We therefore see that, if we continue like this for several iterations, we will get

$$\begin{aligned}
Q^t\vec{p}(0) = c_1\lambda_1^t\vec{x}_1 + c_2\lambda_2^t\vec{x}_2 + \cdots
\end{aligned}\tag{25}$$
