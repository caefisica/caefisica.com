The Grand - canonical ensemble

From (29) we may determine the partition function

$$\begin{aligned}
Z &= \sum_{m_1,m_2,\ldots} e^{-\beta E}\,\delta\left(\sum_j m_j = N\right)
\end{aligned}\tag{31}$$

← See also Eq (70)

this is a constrained sum; we need to sum over an enormous number of states, but only select those which satisfy a certain constraint. Sums like this are very very difficult to handle.

Instead, we will follow a different approach. Imagine that our system is connected not only to a heat bath, but also to a particle bath. that is, a bath" which may exchange particles with our system

S                             Reservoir

then N is no longer fixed. and we will no longer have a restriction in our sum. In order for things not to get completely out of control we impose that the average number of particles be fixed at some value N

Impose:

$$\begin{aligned}
\sum_j \langle m_j\rangle &= N
\end{aligned}\tag{32}$$
