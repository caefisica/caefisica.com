We may compute this resulting sum if we assume that $N \to \infty$. In this case it resembles the geometric series, which converges because $\tanh J < 1$. We just need to be a bit careful because the geometric series starts at $r = 0$. So we write

$$\chi = \frac{N}{T}\left[1 - 2 + 2\sum_{r=0}^{\infty}\tanh^r \beta J\right] = \frac{1}{T}\left[-1 + \frac{2}{1 - \tanh \beta J}\right]$$

Simplifying we get

$$\begin{aligned}
\chi &= \frac{N}{T}\left(\frac{1 + \tanh(J/T)}{1 - \tanh(J/T)}\right)
\end{aligned}\tag{3.9}$$

This result is shown in Fig. 3.7. As can be seen, it diverges as we approach $T \to 0$.
