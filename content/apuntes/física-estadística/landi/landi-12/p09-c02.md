$\tau_N = \sigma_N \sigma_{N-1}$

These $\tau_n$ also take on the values $\pm1$. To find the inverse formulas we use the fact that $\sigma_n = \pm1$, so $\sigma_n^2 = 1$. Moreover, $1/\sigma_n = \sigma_n$ (I think this property quite entertaining). We then get

$\sigma_1 = \tau_1$

$\sigma_2 = \tau_2/\sigma_1 = \tau_2\tau_1$

$\sigma_3 = \tau_3/\sigma_2 = \tau_3\tau_2\tau_1$
